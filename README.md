# PixelPilot

> Turn media into business momentum.

PixelPilot is an AI-powered business media copilot for small and growing businesses. It is being built for the Pixels to Products — Cloudinary AI Hackathon 2026, Track PS-03 — Your Media-Savvy Startup.

## Product loop

Upload → Understand → Optimize → Recommend → Create → Grow

## Planned core capabilities

- Cloudinary-powered media upload and management
- AI media understanding and health scoring
- Searchable product/media library
- Cloudinary transformations for platform-ready variants
- AI business recommendations
- Natural-language business copilot
- Campaign generation
- Analytics and media readiness insights

## Local setup

Run npm install, then npm run dev.

Create .env.local from .env.example and add your own Cloudinary, Supabase, and AI credentials.

## Security

Never commit .env.local or API secrets. Only .env.example belongs in the repository.
